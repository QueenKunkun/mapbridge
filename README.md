# MapBridge

在浏览器里直接迁移地图收藏夹：百度地图 ↔ 高德地图。

数据全程留在本地：扩展复用地图站点自身的登录会话读写收藏，**无云端服务、无上传、无需任何 API Key**。

> 当前已验证：**百度地图 ↔ 高德地图** 的提取与导入。腾讯地图暂不支持（选择器中已隐藏）。

## 功能特性

- **提取收藏**：从已登录的收藏页拦截站点自身的收藏接口响应（`getFav` / `favdata`），不抓 DOM、不依赖脆弱的页面选择器。
- **预览与编辑**：导入前可对提取列表重命名、搜索过滤、删减（编辑结果保留在列表中）。
- **导入收藏**：复用目标页会话，按"WGS-84 坐标 + 名称"的确定性指纹去重后，与目标账号已有收藏合并导入。同一收藏重复导入不会生成重复项。
- **路线迁移**：支持已识别的路线收藏预览，以及百度地图与高德地图之间的驾车、公交、步行和骑行路线导入。
- **坐标系转换**：内置 BD-09（墨卡托）→ GCJ-02 → WGS-84，落地位置准确。
- **导出当前地图**：在预览页与首页一键提取当前已登录地图的收藏并下载为 JSON 文件。
- **通用格式导入/导出**：POI 可导入或导出 GPX 1.1、KML 2.2；Route 也可导出为 GPX route/KML 线段。两种标准格式可能丢失部分 MapBridge 字段，完整恢复请使用 MapBridge JSON。
- **从文件导入**：上传任意 MapBridge 导出文件（`.json`，实为一张收藏表），预览后立即导入其他地图（无需先打开来源页）。
- **导入撤销**：每次导入都会记录本次实际写入的收藏 id，导入完成后可在弹窗结果页或设置页"历史任务"中一键撤销，只删除本次导入项，不影响原有收藏。
- **登录态检测**：popup 探测收藏页是否已打开并已登录，未登录时给出黄色"未登录"提示（选择器经真实页面两种状态实测验证）。
- **开发工具**（仅开发构建）：一键备份并清空高德收藏，用于重置测试数据。
- **百度自动导入**：支持从高德到百度的双向迁移，自动识别并匹配已有收藏。
- **高德新版本支持**：适配高德地图 SSR 新版本（`/ssr/faves`），解决 CSRF token 问题。

## 工作原理

1. ISOLATED 内容脚本把扩展桥接到地图页的 MAIN 世界执行器。
2. 提取：MAIN 执行器捕获站点自身的收藏接口响应，归一化为统一的 `CanonicalPlace`。
3. 导入：读取目标端已有收藏，按 `md5(normalize(name) + "|" + wgs84.lng.toFixed(5) + "|" + wgs84.lat.toFixed(5))` 的确定性指纹去重，通过站点自身的同步接口合并提交；该 id 稳定，重复导入不会生成重复项。

所有操作都在你已登录的页面会话内完成。

## 安装 / 开发

```bash
pnpm install
pnpm dev:build     # 开发版 → .output/chrome-mv3-dev（含 DEV 标识与开发工具）
```

然后在 `chrome://extensions` → *加载已解压的扩展程序* 选择 `.output/chrome-mv3-dev`（开发版）或下面构建的生产目录。

生产构建（DEV 标识与 dev-only 功能会被移除）：

```bash
pnpm build         # 生产版 → .output/chrome-mv3（无 DEV 标识）
pnpm test          # 单元测试
pnpm compile       # 类型检查
```

> 注意：开发版和生产版输出到不同目录，请勿混用；之前 `dev:build` 会覆盖 `chrome-mv3` 的坑已修复。

## 使用方法

1. 打开 popup，选择 **来源 → 目标**（如 百度地图 → 高德地图）。
2. 打开来源收藏页（popup 会自动检测已打开的收藏页并显示登录态）。
3. **提取** → 预览 / 编辑列表 → **导入** → 查看结果报告。
4. 也可在 popup 顶部切换 **导出当前地图** 或 **从文件导入** 模式；导入完成后结果页与设置页"历史任务"均可 **撤销**。

## 项目结构

| 路径 | 用途 |
|---|---|
| `entrypoints/popup` | 迁移向导（选择 → 提取 → 预览 → 导入 → 报告） |
| `entrypoints/options` | 设置、任务历史、适配器状态、开发工具 |
| `entrypoints/background` | 任务编排、消息路由、内容脚本桥接 |
| `entrypoints/*-main.content.ts` | 各地图页的 MAIN 世界执行器 |
| `adapters/` | 各平台归一化 / 导入载荷构造 |
| `core/` | 任务状态机、去重、坐标转换 |
| `utils/` | 桥接协议、消息、存储辅助 |

设计笔记见 `docs/01-architecture.md`–`docs/04-user-workflow.md`（内部文档）。
